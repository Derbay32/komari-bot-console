# 控制台管理员凭据持久化与单次初始密码输出

控制台改用 SQLite 保存管理员凭据。
首次启动时服务端生成随机密码。
数据库持久化取消手工生成密码哈希的部署步骤。

密码遗失或需要轮换时，服务端重置命令生成新的随机密码。
重置命令撤销旧登录会话。
服务端只在凭据事务提交成功后输出一次密码。

登录校验、会话凭据指纹和密码重置读取同一份当前凭据。

- 状态：已接受
- 日期：2026-10-30

## 决策

- 使用 `console_admin_account` 表保存唯一管理员。
- 表保存用户名、scrypt 密码哈希和随机初始密码标记。
- 表保存提醒关闭状态、创建时间和更新时间。
- 只根据密码缺失执行初始化。
- 密码为 NULL 或空值时生成新密码。
- 初始化时把用户名设为 `admin`。
- 已有有效密码时保留用户名和密码。
- 哈希非空但格式无效时返回错误。
- 格式无效时不覆盖原凭据。
- 初始化前生成并哈希候选密码。
- 初始化在 `BEGIN IMMEDIATE` 事务中重新读取状态。
- 并发启动只有一个实例提交成功。
- 凭据事务提交成功后，只有提交成功的实例输出用户名和明文初始密码。
- 正常重启不重新生成密码。
- 正常重启不再次输出密码。
- 如果提交成功后进程在输出日志前退出，重启不恢复密码。
- 操作人员使用服务端密码重置命令恢复登录。
- 认证接口每次从 SQLite 读取当前凭据。
- 控制台认证环境只保留站点来源和数据库路径。
- 机器人后端配置保持原有加载方式。
- 只在 Web 服务启动阶段执行密码缺失时的首次初始化。
- 服务端密码重置命令也生成新的随机初始密码。
- 生产构建不生成管理员账户或密码。
- 类型检查不生成管理员账户或密码。
- 维护通知 Worker 启动不生成管理员账户或密码。
- 提供只在服务端执行的密码重置命令。
- 重置命令读取已配置的绝对数据库路径。
- 重置命令不使用默认或备用数据库路径。
- 重置命令不接受任何参数。
- 重置不要求旧密码或浏览器登录。
- 重置在写入事务外生成并哈希新密码。
- 重置在 `BEGIN IMMEDIATE` 事务中重新读取账户。
- 重置保留非空密码记录的现有用户名。
- 重置把缺失或空密码记录的用户名设置为 `admin`。
- 重置直接替换非空但格式无效的密码哈希。
- 重置保留有效的原创建时间。
- 重置写入新的随机盐 scrypt 哈希。
- 重置把随机初始密码标记设置为已启用。
- 重置把提醒关闭状态设置为未关闭。
- 重置在同一事务中删除全部登录会话。
- 重置事务失败时回滚账户和会话写入。
- 重置只在事务提交成功后输出一次新密码。
- 重置不修改通知、发送尝试、发送历史和登录限流记录。
- 重置不要求停止维护通知 Worker。
- 构建把重置命令编译到 `dist/admin-tools`。
- 构建把重置命令复制到 standalone 产物。
- 生产产物运行重置命令时不依赖源码树、TypeScript 工具或 `NODE_PATH`。
- 会话记录保存凭据指纹。
- 登录校验完成后、写入会话前再次核对当前凭据。
- 凭据变化时拒绝本次登录。

## 后果

- 控制台认证部署不再需要 `CONSOLE_ADMIN_USERNAME` 和 `CONSOLE_ADMIN_PASSWORD_HASH`。
- 启动日志包含一次明文初始密码。
- 包含该密码的日志必须限制为凭据级访问权限。
- 数据库和备份包含密码哈希，不包含明文密码。
- 密码遗失时使用服务端重置命令恢复登录。
- 重置后旧密码不能登录。
- 重置后旧会话的受保护请求失败。
- 重置不删除通知、发送尝试、发送历史和登录限流记录。
- 重置不要求停止维护通知 Worker。
- 重置命令的终端输出包含一次明文新密码。
- 包含新密码的终端输出必须限制为凭据级访问权限。
