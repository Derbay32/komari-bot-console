# 控制台管理员凭据持久化与单次初始密码输出

控制台管理员凭据从环境变量迁移到 SQLite。首次启动时服务端生成随机密码。服务端只在凭据事务提交成功后输出一次密码。数据库持久化取消手工生成密码哈希的部署步骤。登录校验、会话凭据指纹和密码重置读取同一份当前凭据。

- 状态：已接受
- 日期：2026-10-30

## 决策

- 使用 `console_admin_account` 表保存唯一管理员。
- 表保存用户名、scrypt 密码哈希和随机初始密码标记。
- 表保存提醒关闭状态、创建时间和更新时间。
- 只根据密码缺失执行初始化。
- 密码为 NULL 或空值时生成新密码。
- 初始化时把用户名设为 `admin`。
- 已有有效密码时保留用户名和密码。
- 哈希非空但格式无效时返回错误。
- 格式无效时不覆盖原凭据。
- 初始化前生成并哈希候选密码。
- 初始化在 `BEGIN IMMEDIATE` 事务中重新读取状态。
- 并发启动只有一个实例提交成功。
- 凭据事务提交成功后，只有提交成功的实例输出用户名和明文初始密码。
- 正常重启不重新生成密码。
- 正常重启不再次输出密码。
- 如果提交成功后进程在输出日志前退出，重启不恢复密码。
- 操作人员使用服务端密码重置命令恢复登录。
- 认证接口每次从 SQLite 读取当前凭据。
- 控制台认证环境只保留站点来源和数据库路径。
- 机器人后端配置保持原有加载方式。
- 只在 Web 服务启动阶段生成管理员账户和随机初始密码。
- 生产构建不生成管理员账户或密码。
- 类型检查不生成管理员账户或密码。
- 维护通知 Worker 启动不生成管理员账户或密码。
- 会话记录保存凭据指纹。
- 登录校验完成后、写入会话前再次核对当前凭据。
- 凭据变化时拒绝本次登录。

## 后果

- 控制台认证部署不再需要 `CONSOLE_ADMIN_USERNAME` 和 `CONSOLE_ADMIN_PASSWORD_HASH`。
- 启动日志包含一次明文初始密码。
- 包含该密码的日志必须限制为凭据级访问权限。
- 数据库和备份包含密码哈希，不包含明文密码。
